## 账号角色说明
| 角色 | 可访问功能 |
|------|------------|
| 管理员 | 数据总览、课程管理、章节管理、学习统计、人员管理、课程导入、学期管理 |
| 教师 | 数据总览、课程管理、章节管理、学习统计 |
| 学生 | 不可访问教师管理端，访问管理员路由会被强制跳回仪表盘 |

> 测试时建议先用**管理员账号**验证完整功能，再用**教师账号**验证教师可见范围，最后用**学生账号**验证无权限拦截。
